Como Testar

  1. Clique no botão "Copiar" ao lado da chave desejada
  2. Volte para a ferramenta principal
  3. Cole a chave no campo de entrada (Ctrl+V ou Cmd+V)
  4. Clique em "Decompor" ou pressione Enter
  5. Veja os resultados aparecer na tabela
  6. Teste também o botão "Câmera" para simular leitura de código de barras

Testes Recomendados

Teste 1: Validação Básica

  • ✅ Digitar uma chave válida de 44 dígitos
  • ✅ Resultado esperado: Tabela com informações decompostas

Teste 2: Validação de Erro

  • ❌ Tentar digitar menos de 44 dígitos
  • ❌ Tentar digitar caracteres não numéricos (serão removidos automaticamente)
  • ❌ Tentar usar um dígito verificador inválido
  • ✅ Resultado esperado: Mensagem de erro apropriada

Teste 3: Responsividade

  • ✅ Abrir em desktop (1920px+)
  • ✅ Abrir em tablet (768px)
  • ✅ Abrir em mobile (320px)
  • ✅ Resultado esperado: Interface adaptada para cada tamanho

Teste 4: Câmera (se disponível)

  • ✅ Clicar em "Câmera"
  • ✅ Permitir acesso à câmera
  • ✅ Mostrar um QR code com a chave (pode usar um app gerador online)
  • ✅ Resultado esperado: Chave lida automaticamente e tabela preenchida

Teste 5: Cópia de Resultados

  • ✅ Decompor uma chave
  • ✅ Clicar em "Copiar Resultados"
  • ✅ Botão muda para "Copiado!" com cor verde
  • ✅ Colar em um editor de texto (Ctrl+V)
  • ✅ Resultado esperado: Todos os dados formatados corretamente

Teste 6: Nova Busca

  • ✅ Decompor uma chave
  • ✅ Clicar em "Nova Busca"
  • ✅ Campo de entrada é limpo
  • ✅ Tabela é ocultada
  • ✅ Foco volta ao campo de entrada
